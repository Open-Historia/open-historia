## Purpose / evidence rules

This report ends the incremental source-patch sweep after Checkpoints 01–11. Every source patch lives **in the existing working tree**, not just in a ZIP. It **does not** certify that all 17 original defects are reproduced/fixed in packaged Electron, live provider, persisted saves or upstream Beta. Previous checkpoint-level details, known debt and separate tracks remain recorded in `docs/world-state.md` and the [joint QA tracker](https://chatgpt.com/space/page_92442ee376d0819199cc817bda93fa82).

Use these categories consistently:
- **Source fix / live QA required**: concrete defect corrected and native regression built; live reported case not replayed.
- **Partial**: bounded improvement exists but cannot claim the underlying reported behavior is eliminated.
- **Design dependency**: existing native contract cannot represent the requested behavior without an approved architecture decision.
- **Evidence watch**: original reports are incomplete for verifying the alleged native defect or provider cause.

## 2026-11-01 post-v0.2 source repair linked to #003: Statistics definition concurrency

**Original #003 remains PARTIAL; original QA score remains 7/17 source-fixed awaiting live QA.** Actual desktop `server/libraryStore.js` and web `src/runtime/web/libraryStore.js` return `assetStatus.stats` as a Boolean indicating that `stats.json` exists. The pre-existing scenario-authoring checks correctly compared that flag, but **could not detect a concurrent definition replacement when both versions existed** (`true` before and after). This exposed a genuine stale-authoring gap, without justifying a new Statistics schema or native ledger.

After red-before-green tests, the reviewed starting-baseline Apply, the dedicated **Save Statistics sheet definition (keep proposals)** action, and the normal Scenario Save all re-read the actual current `stats` asset with a no-cache request and compare its normalized, serialized content with the last saved definition **before writing any country values or replacing a definition**. A changed native binding, metric bounds, or removed/missing asset rejects and asks the author to reload; a truly identical definition remains allowed. Main Save does not add a new requirement when the existing Stats asset could not be loaded (it already preserves that asset). The comparison uses the **last saved** editor definition, not unsaved draft state; existing Boolean `assetStatus` stays unchanged in desktop/web stores. This is a read-before-write guard, **not** an atomic cross-client transaction or a claim that every simultaneous race can be eliminated. None of the three paths silently modifies national Stats, GDP or legacy archived evidence.
