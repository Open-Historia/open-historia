The browser version is a demo — it streams the world map over the network, so expect lag. The desktop app runs locally and is how the game is meant to be played.

Up and running in minutes

Three steps to play

No accounts, no store, no build tools to wrangle. Download the app for your system, open it, and play.

I

Download

Pick the download for your system: an installer on Windows, a zip on macOS, a .deb package on Linux (AppImage below it for everything else).

II

Open it

Run the installer on Windows, or drag the app to Applications on macOS. Nothing else to set up — the app brings everything it needs with it.

III

Play

Open Historia opens in its own window. The world map downloads once, with a progress bar, then you pick a scenario and start reshaping history.

Run Open-Historia-Setup.exe and follow the installer, then open Open Historia from the Start Menu. If Windows SmartScreen warns, choose More info → Run anyway — the installer isn't code-signed yet.
Unzip the download and drag Open Historia into your Applications folder. The first time, right-click it and choose Open — the app isn't code-signed yet, so macOS asks for confirmation once. If it says the app is damaged instead, macOS quarantined the download — clear it with xattr -dr com.apple.quarantine "/Applications/Open Historia.app" and open it again.
On Debian, Ubuntu and derivatives install the .deb (sudo apt install ./open-historia_amd64.deb) — it lands in your applications menu like any other program. Otherwise use the AppImage: chmod +x Open-Historia-x86_64.AppImage and run it, nothing installed system-wide.

Grow the network

Host a server node

Run a small node on your own device to help players load the world map faster. It's deliberately safe: a node only ever serves read-only map data, verified byte-for-byte by checksum. It never touches anyone's games, accounts, or AI keys, and never runs their code — so it can't be turned against players.

I

Install in one click

Download the node and run install.bat (Windows) or install.sh (macOS/Linux). It sets everything up and downloads the verified map content for you.

II

Put it online

Expose it over HTTPS — a free Cloudflare Tunnel is easiest (no open ports, hides your IP). The README walks you through it step by step.

III

You're live

Your node registers itself and starts serving straight away — no waiting, no extra steps on your side. Players only ever use nodes listed in the project's signed directory, and an admin can pause or remove any node from it at any time.

🖥️ Host a server Read the setup guide

Good to know

Questions & requirements

Do I need to install anything else?

Just Node.js, and the launcher offers to install it for you if it's missing (via winget on Windows, Homebrew on macOS, or your package manager on Linux). Everything else — including all map data — ships inside the download.

Is it really free?

Yes. Open Historia is free and open source under the MIT license. The AI features connect to an AI backend you configure — see the README or ask in Discord for setup help.

Where does it run — is my data uploaded?

The game runs locally on your own machine and opens in your browser at localhost:3000. Your saves and scenarios stay on your computer.

How do I update later?

Run the Update Open Historia script that comes with your install — it fetches the latest version while preserving your saves, scenarios, and map data. You can choose the Stable or Beta channel when updating.

What about mobile?

Download the Android APK and open it — that is the whole setup. Your games live on the phone and the world map is kept there after it downloads the first time, so there is no server to run and nothing to point it at.

Can I help by hosting a server?

Yes! Running a content node caches the game's map data and serves it to nearby players, so everyone loads faster. It's a one-click install and completely safe — a node only serves read-only, checksum-verified map files and never touches games, accounts, or API keys. See Host a server node.
